## 1. Why a document database for Topez Farms
The MySQL design in Portfolios 1-3 works well for stock, payments and
deliveries, where consistency matters but the products and orders tables favour document model better:

- **Products have different attributes.** Palm oil has volume and packaging,
  cassava has moisture percentage and harvest window, and palm fruit bunches
  have yield and pick-up details. In MySQL this means many mostly-empty
  columns or extra tables. A document lets each product carry its own
  `attributes` object.
- **An order is read as one unit.** Items, payments and deliveries are almost
  always read together with the order, so storing them inside the order
  document avoids joins.


**Synthetic data:** the 20,000 bulk orders were generated by a loop in
`03_bulk_orders.js` (guided by `Claude AI`) that cycles through the three products, customers, states
and statuses. It is repeatable but not realistic. 
One of the limitations is that bulk orders with status `DELIVERED` or `PARTIALLY_DELIVERED` have an empty
`deliveries` array, so delivery queries are only meaningful for the hand-made orders.

## 7. How to reproduce
1. Start MongoDB (`brew services start mongodb-community`) and open `mongosh`.
2. Run `mongosh --file scripts/01_products.js`, `02_orders.js`, `03_bulk_orders.js` in that order. 
Please run each once, because MongoDB accepts duplicate documents unless a unique index exists.
3. Run the queries in `04_queries.js` individually in the shell (`--file` prints nothing unless `printjson` is used). 
4. Run the explain commands, then `scripts/05_indexes.js`, then repeat them.

## 8. Challenges and lessons
- I first installed only `mongosh` (the client), so connecting failed
  with `ECONNREFUSED` on port 27017. The server package was missing.
- Homebrew couldn't load the formula from an untrusted tap and needed the
  `mongodb/brew` tap to be trusted before the `install` worked.
- `mongosh --file` printed no output, because script runs only print explicit
  `print` or `printjson` calls. I checked results in the interactive shell.
